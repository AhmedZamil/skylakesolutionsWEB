# Sky Lake Solutions

Marketing site for [skylakesolutions.com](https://skylakesolutions.com).

The stack is Next.js 15 (App Router), React 19, Tailwind CSS 4, and Framer Motion. Diagrams are inline SVG: paths draw in with `pathLength`, nodes pop on scroll, and connector lines use a dashed stroke animation.

## Scripts

```bash
npm install
npm run dev
npm run build
```

Open [http://localhost:3000](http://localhost:3000).

## Contact form

The form does not post to a server. It opens the visitor’s mail app addressed to `hello@skylakesolutions.com`.

## Brand

Colors come from the studio logo: black, royal blue (`#1f6bff`), and cyan (`#00d8f0`). Logo files live in `public/`.
